# PhotoViewerApp

PhotoViewerApp is a JavaFX-based application that allows users to manage and view their photo collections. The application supports multiple users, each with their own albums and photos. Users can add captions, tags, and search for photos based on various criteria.

## Features

- **Admin Functionality**:
  - Create and delete user accounts.
  - Manage user data.

- **User Functionality**:
  - Create, rename, and delete albums.
  - Add photos to albums and organize them.
  - Add captions and tags to photos.
  - Search photos by:
    - Date range.
    - Tags (AND/OR logic).
  - View photos in:
    - Grid format.
    - Slideshow format.

- **Photo Management**:
  - Copy or move photos between albums.
  - View photo details, including captions, tags, and dates.

## Technologies Used

- **JavaFX**: For building the graphical user interface.
- **Java**: Core programming language for application logic.
- **FXML**: For defining UI layouts.
- **Serialization**: For saving and loading user data.

1. Clone the repository:

   git clone <repository-url>
   cd PhotoViewerApp

2. Open the project in your Java IDE (e.g., IntelliJ IDEA, Eclipse).

3. Ensure you have JavaFX configured in your IDE.

4. Run the Photos class located in Photos.java.
